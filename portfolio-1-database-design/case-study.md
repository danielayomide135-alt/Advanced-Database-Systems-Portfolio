# Case study: Bank Platform

# Organisation and nature of the system
The aim of this project is to model a Bank platform that provides digital service to individual and business

# Database users
Auditors, Customer Service Officers, Account Officers, Bank Tellers and Administrator

# Major Data Stored
Employee Data, Customer Data, Loan Data, Account Data, Withdrawal Data, Deposit Data

# Key Operations
- Account Opening
- Deposits
- Withdrawals
- Payment Processing
- Balance Management
- Card Management
